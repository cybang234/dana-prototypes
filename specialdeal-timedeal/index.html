1. 카운트다운 게이지 · 진입 모션

· 노출 조건 — 모듈이 뷰포트에 30% 이상 보일 때 1회 재생 (threshold 0.3), 노출 전에는 fill 100% 대기 · 게이지 fill 100% 꽉 찬 상태 → 남은시간 비율 지점까지 감소 · Duration 1.6s / cubic-bezier(0.4, 0, 0.2, 1) — 감소 후 실시간 카운트 시작 · 두 모듈(스페셜딜·타임특가)이 같은 종료시각 공유 — 게이지·타이머 동기화 · fill 폭 = 남은시간 ÷ 전체 딜 시간(24h), 이후 초 단위로 계속 감소 · 실지면 패널에서 스크롤로 30% 노출 트리거 직접 테스트 가능 (↻ 로딩 테스트 버튼 = 강제 재생)

2. 카운트다운 · 숫자 롤링 · 종료 상태

· 타이머 "종료시간까지 HH:MM:SS 남음" — 1초 단위 갱신, 시계 아이콘은 정적 · 숫자는 슬롯머신 롤링 — 변경된 자리만 세로 슬라이드 0.28s cubic-bezier(0.4, 0, 0.2, 1) · 종료 시 — fill 제거(트랙만 남음), 타이머 회색 + "오늘 딜 종료"(문구 확정 필요) · 타임특가 인상 예고 배지도 동시에 회색 전환 + "오늘 딜 종료"로 교체 · 게이지 위 핀 — 제외 확정 (2026-09-01)

3. 카테고리 chip (스페셜딜)

· '전체' chip 필수, 기본 선택 (selected = solid 전환) · chip 선택 시 리스트 갱신 — 스켈레톤 320ms 노출 후 데이터 즉시 교체 (랭킹 모듈과 동일) · 선택 chip 자동 스크롤 — 스트립 좌측 패딩(16px) 안쪽 정렬, 끝쪽 chip은 클램프 · 빈 카테고리(상품 0개)는 스켈레톤 없이 즉시 빈 상태 노출 — 실서비스는 해당 chip 미노출 정책

4. 캐러셀

· 스페셜딜 — 컬럼(카드 3개 = w328) 단위 scroll-snap, 1회 스와이프 = 1컬럼, 컬럼 간격 12 · 타임특가 — 카드(w280) 단위 snap, 다음 카드 peek 67, 카드 간격 12 · 공통 — scroll-padding-left 16, 스크랩 버튼 탭 시 토글(레드 전환)
